01 / SOBRE MIM

Mais do que código.
Soluções para pessoas.

Sou Marlon Gonçalves Silva, desenvolvedor web com 3 anos de experiência prática criando projetos e explorando tecnologias para a web.

Já desenvolvi diferentes sites e projetos, incluindo trabalhos publicados e entregues para clientes. Meu objetivo é entender o que cada negócio precisa e transformar isso em uma presença digital clara, funcional e visualmente profissional.

Trabalho principalmente com desenvolvimento front-end, sem deixar de explorar back-end, APIs e bancos de dados quando o projeto pede.
